01 / HIERARCHY & ROUTING

Cascading Permanent IDs

<Subtopic == QA-TRG-BS, name = Basics>...</Subtopic>Tier 3 Subtopic container absorbed live by 10 Registry (inherits Domain-Chapter prefix).
<Concept == QA-TRG-BS-FR, name = Ratios>...</Concept>Tier 4 Concept container absorbed live under its parent Subtopic.
<MC == QA-TRG-BS-FR-MC1, name = Side Ratio>...</MC>Tier 5 Micro Concept — permanent Full Base ID used for step tracking.
<target == QA-TRG-BS-FR>Inside <Qn>: ships the question directly into the matching chapter’s questions.html and Concept bucket.
<box points = (1,1),(8,1),(8,5),(1,5) path = QA-TRG-BS-FR></box>Portal box on the study canvas; keeps your authored box dimensions and opens Study / Shallow Mode for that path.
02 / STEP ENCLAVE & DIAGRAMS

Grid Geometry & Labels

<enclave points = (1,1),(13,1),(13,6),(1,6) background-color = #FFFFFF color = #CBD5E1></enclave>One per <step> max. Rips that exact grid rectangle as the step’s viewport; supports all <box> attributes & shorthand <enclave = (x1,y1),(x2,y2)>.
<box points = (x1,y1),(x2,y2),(x3,y3),(x4,y4) background-color = #FFF color = #123>Body</box>4-point perimeter polygon box on the grid. Aliases: bg-color, text-color.
<box w points = (x1,y1),(x2,y2),(x3,y3),(x4,y4) text-color = #0F172A>Label</box w>Clean borderless grid text block (no box outline or underline; rotates along angled bottom edge if slanted).
<line color = #2563EB>(1,1),(4,1),(4,5)</line>Standard grid polyline drawn underneath boxes (hex colors only).
<line m color = #EF4444>(2,3),(8,3)</line m>Priority over-box polyline drawn above boxes.
<line d line-color = #2563EB text-color = #1D4ED8 floating = 1.5mm>(2,5),(2,2) O = 4</line d>Labeled over-box connector with upright text floating ±Xmm from the line (negative flips side).
<arc points = (2,6) (8,6) depth = 1.2 color = #D97706 text-color = #B45309 floating = 1.5mm>θ</arc>Curved quadratic arc between 2 points (supports decimals & negative depth). Use <arc m ...>...</arc m> to draw above boxes.
03 / QUESTIONS & STEPPED EXPLANATIONS

Quiz & PYQ Batch Format

<qn all mode = exam> ... </qn all>Quiz group container (mode = normal default, or mode = exam with single Submit footer).
<Qn> ... </Qn>Individual question block inside <qn all> or questions.html.
<id == QA-TRG-BS-FR-1>Permanent unique Question ID (used for Tracker history and disk step write-back).
<type = Quantitative Aptitude>Question format tag for Question Index breakdown.
<text = Find <math == sin A>.>Question prompt (supports inline math, tables, and study tags).
<Options><A = ...><B = ...><C = ...><D = ...></Options>Answer choices block, paired with <answer = A>.
<explanation><step 1 - QA-TRG-BS-FR-MC1>...</step 1><step 2 - Tu>...</step 2></explanation>Step-by-step explanation tagged with permanent Full Base IDs, TG (general), or Tu (unmapped gap).
04 / MATH SHORTHAND

Inline <math == ...> (Offline KaTeX)

<math == a/b> / <math == (a+b)/(c+d)>Display fraction \dfrac{a}{b}.
<math == a * b> · <math == x // y> · <math == a div b>Multiplication (×) and division (÷).
<math == sqrt(x^2 + 1)> · <math == cbrt(27)>Square root and cube root (supports nesting).
<math == tri ABC ~= tri DEF>Triangle symbol (△) and congruence (≅).
<math == theta, alpha, beta, pi, inf, <=, >=, !=>Greek letters, infinity, and comparison operators.
05 / STUDY TAGS, TABLES & CSS GRID

Notes, Callouts & Styles

<table r = 2 c = 2><c11 = A><c12 = B><c21 = C><c22 = D></table>Compact MKML table (cells support nested HTML/MKML).
<ud = label>word</ud> · <ud = n **rl**>word</ud>Underlined grammar/concept label; add **rl** to hide until reveal in questions.
<x = wrong> · <ok = right> · <hide == spoiler>Inline strike/check highlights and click-to-reveal spoiler.
<rule == ...> · <trap == ...> · <chain == A -> B -> C>Rule callout, exam-trap warning, and arrowed reasoning chain.
<grid pos="2, 4" span="11, 8">...</grid>Explicit grid card placement on the 03 Preview sheet.
<css-id: 123> · <link-css-id: 123> · grid-text-align: (col, row);Scoped stylesheet linking between chapter .css and .html notes, plus exact CSS coordinate anchoring.
